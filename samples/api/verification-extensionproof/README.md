# Internal Linux affinity example

This maintainer-only sample uses the A23 internal friend assembly. Build the native
`nativeweave-engine-extensionproof` crate first; ordinary source and AOT sample builds
consume that exact precompiled asset. It demonstrates the minimal typed owner pump
and explicit close. The companion tests demonstrate held-handler/control leases,
queue saturation, producer races and actual finalizer cleanup requests. No public
GUI/GPU/device package or simulated hardware certification is provided.
